# SE-Git-hw

A simple Python project created to practice Git and GitHub workflows, including branches, issues, pull requests, and merge conflicts.

## Requirements

- Python 3
- Git

## Clone the Repository

```bash
git clone https://github.com/femibams/SE-Git-hw.git
cd SE-Git-hw
```

## Run the Greeting Program

The greeting program asks for your name and displays a personalized greeting.

```bash
python3 hello.py
```

Example:

```text
What is your name? Femi
Hello, Femi!
```

## Run the Apple Program

The apple program displays a short message about apples.

```bash
python3 apple.py
```

Output:

```text
I eat apple
```
